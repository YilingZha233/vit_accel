# TinyViT-21M: 1,000-image HPS accuracy evaluation

Imported and audited on 8 November 2026. Actual acquisition date is not independently established by the board clock. This report records measured results from the supplied `attachments.zip`; no inference was rerun during import.

## Main result

Both complete models executed on the DE1-SoC Cyclone V **HPS ARM CPU**, using ncnn and two CPU threads. Native INT8 reduced top-1 accuracy by **1.3 percentage points** and top-5 accuracy by **0.4 percentage points**, relative to FP32 on the same 1,000 images.

| Metric | FP32 | Native ncnn INT8 | FP32 minus INT8 |
|---|---:|---:|---:|
| Evaluated images | 1,000 | 1,000 | — |
| Execution failures | 0 | 0 | — |
| Top-1 correct | 849 | 836 | 13 |
| Top-1 accuracy | 84.9% | 83.6% | 1.3 pp |
| Top-1 Wilson 95% interval | 82.55–86.99% | 81.18–85.77% | Not a paired loss interval |
| Top-5 correct | 970 | 966 | 4 |
| Top-5 accuracy | 97.0% | 96.6% | 0.4 pp |
| Top-5 Wilson 95% interval | 95.75–97.89% | 95.29–97.56% | Not a paired loss interval |

Top-1 means the highest-scoring class matches the label. Top-5 means the label appears among the five highest-scoring classes. Failures refer to execution failures, not classification errors. The net difference of 13 correct predictions does not identify how many individual images improved or worsened. Aggregate counters cannot recover prediction agreement, per-image transitions, logit error or a paired accuracy-loss interval. Overlapping per-model intervals do not establish equivalence or statistical significance.

## Dataset and numerical scope

- Source reported by the user/workflow: [Kaggle ImageNet 1000 (mini), ifigotin](https://www.kaggle.com/datasets/ifigotin/imagenetmini-1000), validation portion (3,923 candidates in the inspected download).
- Evaluation manifest: 1,000 unique image IDs and 1,000 unique recorded content hashes, spanning **676 distinct checkpoint labels**. It is a sampled validation subset, not one image per class and not the full 50,000-image ImageNet validation benchmark.
- Full 1,000-class classifier remains active; prediction is not restricted to the 676 observed labels.
- Label preparation maps the complete sorted WNID folder inventory to zero-based checkpoint class indices. The downloaded images, Kaggle ZIP and subset `provenance.json` were not included in this upload, so original pixel contents, source selection seed and folder assignments were not independently revalidated here.
- Inputs were prepared in WSL and supplied identically to both board runs. The returned experiment records RGB, bicubic resize, shorter side 256, center crop 224, ImageNet normalization and FP32 CHW inputs.
- The existing native INT8 model retains its original **ten-image calibration**. Recorded calibration image hashes are disjoint from all evaluation hashes. No recalibration occurred for this comparison.
- This is the deployed ncnn INT8 configuration, **not the Q1 Python simulation or Q4 RTL-compatible simulation**. Native integer kernel/fallback coverage remains unverified. Full-graph inference may include floating-point operators.
- No FPGA fabric accelerator or DMA offload is involved. Q1–Q4 have not been reevaluated on these 1,000 images.

## Execution and supplementary resources

Twenty batches were returned: `fp32_batch_00` through `fp32_batch_09`, and `int8_batch_00` through `int8_batch_09`. Each contains 100 completed evaluations, zero failures, `mode=eval`, `platform_machine=armv7l`, two threads and the expected precision request. Their image IDs exactly match the corresponding slices of the same experiment manifest.

| Measurement from these accuracy runs | FP32 | Native INT8 |
|---|---:|---:|
| Count-weighted mean inference ms | 4,484.101203 | 3,201.316444 |
| Maximum reported batch-process peak RSS MiB | 149.484375 | 72.964844 |
| Sum of batch service-loop seconds | 4,490.255840 | 3,207.422341 |

These are derived from the returned batch summaries. They are **evaluation-mode** measurements with zero warmups and a separate initial inference per batch; model loading repeats per batch. Keep the earlier dedicated 20-call/three-warmup pilots as the historical performance comparison. Service-loop sums omit load, initial inference, bundle checking and shell overhead and are not total experiment duration. No overall median, p95 or standard deviation is reconstructed from batch summaries.

The inference scope is extractor creation, input binding, inference and output extraction on preprocessed inputs. Camera capture, decoding, resizing and normalization are excluded. Peak RSS is per process; the table gives the maximum across ten batch processes, not steady-state memory or a sum of peaks.

Returned environment: Linux `3.12.0-00307-g507abb4-dirty`, `armv7l`, two ARM Cortex-A9 CPUs, `neon` among CPU features, system MemTotal 1,031,824 kB, no swap configured. CPU feature availability does not prove per-operator SIMD execution. This upload does not add CPU utilization, frequency, power or accelerator resource measurements.
